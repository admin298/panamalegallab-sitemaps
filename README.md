# Panama Legal Lab

Este repositorio conserva los cinco sitemaps publicados y el código de entrega de la web en cuatro idiomas.

El estado y el procedimiento actuales de Cloudflare están en [DEPLOYMENT.md](cloudflare/DEPLOYMENT.md). El paquete gratuito publicado y verificado en producción está en [cloudflare/frontend/durable-free](cloudflare/frontend/durable-free/README.txt). El [recibo de activación](cloudflare/frontend/durable-free/activation-receipt.json) identifica los compilados y las comprobaciones de 43 páginas.

Los archivos anteriores de `cloudflare/frontend/` se conservan como historial. Para desplegar, sigue el documento actual enlazado arriba.

Sitemaps: [índice](sitemap-index.xml), [español](sitemap-es.xml), [inglés](sitemap-en.xml), [francés](sitemap-fr.xml) e [italiano](sitemap-it.xml).
